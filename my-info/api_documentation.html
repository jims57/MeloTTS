WebSocket /tts - TTS WebSocket接口
▶

📋 接口描述

通过WebSocket连接进行实时TTS语音合成，支持流式数据传输

📊 连接参数

x-api-key (Header, 必需) - API密钥

📝 WebSocket消息格式

text (String, 必需) - 要合成的文本内容
类型: String | 必填: 是 | 示例: "你好，这是一段测试文本。"
language (String, 可选) - 语言代码
类型: String | 必填: 否 | 默认: "zh" | 可选值: ["zh", "en", "jp", "kr", "fr", "es"]
zh=中文, en=英语, jp=日语, kr=韩语, fr=法语, es=西班牙语
speakerId (Integer, 可选) - 说话人ID
类型: Integer | 必填: 否 | 默认: 0
zh: 0-2, en: 0-4, jp/kr/fr/es: 0
outputSampleRate (Integer, 可选) - 输出音频的采样率
类型: Integer | 必填: 否 | 默认: 22050 | 可选值: [16000, 22050, 24000, 44100]
audioFormat (String, 可选) - 输出音频格式
类型: String | 必填: 否 | 默认: "mp3" | 可选值: ["mp3", "pcm"]
chunkDuration (Float, 可选) - MP3 chunk时长（秒）
类型: Float | 必填: 否 | 默认: 0.25 | 示例: 0.5
值越小响应越快，控制MP3 chunk发送频率
speed (Float, 可选) - 合成音频的语速
类型: Float | 必填: 否 | 默认: 1.0 | 范围: [0.5, 2.0] | 示例: 1.5
取值越大，语速越快。1.0为正常语速，0.5为半速，2.0为两倍速。
startTimeId (Long, 可选) - 开始时间ID，用于消息头
类型: Long | 必填: 否 | 示例: 1752634809864
messageId (Integer, 可选) - 消息ID，用于消息头
类型: Integer | 必填: 否 | 示例: 4
saveAudioFiles (Boolean, 可选) - 是否保存音频文件到服务器
类型: Boolean | 必填: 否 | 默认: false

📤 TTS生成请求示例

WebSocket连接: ws://your-server:port/tts Headers: {"x-api-key": "sk-m2n3b4v5c6x7z8l9k0j1h2g3f4d5s6a7p8o9i0u1"} 发送TTS生成消息: { "text": "你好，这是一段测试文本。", "language": "zh", "speakerId": 0, "outputSampleRate": 16000, "audioFormat": "mp3", "chunkDuration": 0.25, "speed": 1.0, "saveAudioFiles": false, "startTimeId": 1752634809864, "messageId": 4 }

消息头部格式

当同时提供 startTimeId 和 messageId 时，每个音频chunk前会添加12字节头部：

  • 前8字节: startTimeId (Big-Endian Long)
  • 后4字节: messageId (Big-Endian Integer)

✅ 成功响应

返回流式二进制音频数据

❌ 错误响应

错误: 缺少API密钥
{"error": "Missing x-api-key header"}
错误: API密钥无效
{"error": "Invalid API key"}
错误: 文本必填
{"error": "Text is required"}
错误: 不支持的语言
{"error": "Language 'XX' not supported"}
